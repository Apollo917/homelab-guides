# Grafana

**Grafana** is an open-source analytics and visualization platform. It connects to a wide range of data sources —
such as Prometheus, InfluxDB, and Loki — and lets you build interactive dashboards to monitor metrics, logs, and
alerts in real time. In a homelab context, it is most commonly used alongside Prometheus to visualize system and
service metrics collected from exporters like Node Exporter
