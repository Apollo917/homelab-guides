# Vaultwarden

**Vaultwarden** is an unofficial, lightweight open-source implementation of the Bitwarden server API, written in Rust.
It is designed for self-hosting and acts as a drop-in backend for all official Bitwarden clients — browser extensions,
mobile apps, and desktop apps — without requiring the resource-heavy official server stack

Its purpose is to give individuals and small teams full control over their password vault data while remaining
compatible with the polished Bitwarden client ecosystem. Vaultwarden supports the majority of Bitwarden features,
including organizations, collections, TOTP, attachments, and the web vault UI
